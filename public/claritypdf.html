OCR APIサーバー

旧名称: ClarityPDF

OCR APIサーバーは、PDF や画像を受け取り、文字情報を JSON で返す OCR API を Android 端末上で常時提供するアプリです。OCR は端末内（Tesseract / PaddleOCR / ローカル LLM Vision）で実行し、同じ端末の他アプリや同一 LAN の PC から利用できます。画面からの OCR・要約・AI プロンプト、PDF の分解・統合・並べ替え・画像化・編集も引き続き同じアプリで使えます。

文書: 操作マニュアル | プライバシーポリシー

  • ホーム最上部の「API を開始」だけで、この端末が OCR API サーバー（既定ポート 8765）になります。
  • 一度開始すると、アプリを閉じても・プロセスが終了しても・端末を再起動しても自動で再開する常時稼働サービス。
  • 他アプリから Intent で API を開始／停止可能。応答には行ごとのテキスト・信頼度・位置（blocks / box）を含みます。

OCR API

POST http://<端末IP>:8765/ocr      multipart/form-data
GET  http://<端末IP>:8765/health   → {"status":"ok"}
フィールド必須説明
file○PDF または画像（PNG / JPEG / WebP / BMP）
enginetesseract（既定） / paddleocr / llm
lang言語コード。eng（既定）、jpn,eng のように複数指定可。縦書き日本語は jpn_vert
dpiPDF のレンダリング解像度 36〜600（既定 150）
curl -X POST http://192.168.1.10:8765/ocr \
  -F "file=@doc.pdf" -F "engine=tesseract" -F "lang=jpn,eng"
{
  "pages": [ {
    "page": 1, "text": "…", "confidence": 0.92, "source": "OCR",
    "width": 1080, "height": 2400,
    "blocks": [ { "text": "…", "confidence": 0.95,
                  "box": { "left": 40, "top": 120, "right": 620, "bottom": 168 } } ]
  } ],
  "engine": "Tesseract", "languages": ["jpn", "eng"], "dpi": 150, "pageCount": 1
}

box は OCR した画像（width × height、PDF は dpi でレンダリング後のサイズ）上のピクセル座標で、原点は左上です。Tesseract / PaddleOCR は位置を返し、LLM Vision では box を省略します。詳しくは操作マニュアルを参照してください。

常時稼働と他アプリからの起動

  • 常時稼働: フォアグラウンドサービスとして動作し、プロセス Kill（自動再起動）、タスクのスワイプ終了、端末再起動（起動時に自動再開）、約 60 秒間隔のウォッチドッグで復帰します。停止するのは「API を停止」「終了」、通知の「停止」、他アプリからの停止要求のときだけです。
  • 処理中の保持: OCR 処理中は WakeLock と Wi-Fi ロックを保持し、画面オフでも処理を継続します。ホームの「バッテリー最適化から除外する」でスリープ中の応答と自動復帰が安定します。
  • 他アプリから有効化: 明示的 Intent（com.micklab.pdf.START_SERVICE / STOP_SERVICE、任意の int extra port）を startForegroundService() で送ると、画面を開かずに API を開始／停止できます。メーカーの自動起動制御で拒否される端末向けに、透明な起動用 Activity も用意しています。
  • 接続先の表示: ホームに端末の各ネットワークのエンドポイント URL を表示し、タップでコピーできます。処理状況 / ログで開始・停止・リクエスト・エラーの履歴を確認できます。

スクリーンショット

※ ホーム画面以外のスクリーンショットは旧名称（ClarityPDF）時点のものです。

OCR / AI-OCR（画面からの直接実行）

  • OCR / テキスト抽出: PDF・画像から文字を抽出。埋め込みテキストと OCR を区別し、JSON 出力にも対応します。Tesseract（軽量）は日本語（横書き・縦書き）・英語・中国語(簡体/繁体)・韓国語・ギリシャ語・ロシア語・アラビア語・ヘブライ語・数式に、PaddleOCR（高品質）は日本語（横書き・縦書き）・英語・中国語(簡体/繁体)・韓国語・アラビア語・キリル文字に対応します。
  • PDF サマリ（要約）: ファイル全体・ページごとを LLM で要約。「OCR→LLM」または「Vision（ページ画像を直接 LLM へ）」を選べます。
  • AI プロンプト: 任意の指示を入力し、PDF 全体または各ページごとに AI 処理を実行できます。実行中は「中止」で止められます。
  • LLM 連携: Ollama / OpenAI 互換サーバに対応。既定はコンパニオンアプリ LLM AI Server with llama.cpp の「default Vision」「default Chat」で、サーバが停止中なら処理の開始時に自動で起動します。

PDF ツール

  • PDF 編集: テキスト・画像・図形・描画の追加、既存文字の置換／削除。太字／斜体／下線、回転、拡大縮小、リンク（URL）、レイヤーの並べ替え、元に戻すに対応。ページの挿入（前／後／末尾）・削除もできます（最後の 1 ページは削除不可）。
  • 多言語フォント: Noto Sans JP / SC / TC / KR / Arabic / Hebrew / Math など（すべて SIL OFL）を、フォント選択時にその場でダウンロード。アラビア語・ヘブライ語は右→左の連結整形・双方向並べ替えを自動で行います。
  • 分解・統合・並べ替え: ページ抽出、複数 PDF の結合、サムネイルのドラッグによる並べ替え。
  • PDF 画像化 / 画像 → PDF 化: 各ページを PNG / JPEG に（DPI 指定可）、複数画像を 1 つの PDF に。

利用メモ

  • OCR API に認証はありません。信頼できるローカルネットワーク内でのみ有効にし、外部ネットワークには公開しないでください。
  • 受け取ったファイルは端末内で処理して結果を返し、処理後に破棄します。当方のサーバへ送信することはありません。
  • 通信を行うのは「OCR モデル・フォントの初回ダウンロード」「LLM を利用する場合の設定サーバへの送信」「広告の表示」だけです。既定の LLM 接続先は端末内 127.0.0.1 です。
  • メーカー独自の省電力機能による強制停止からは自動復帰できない場合があります。
