GGUF Generator

GGUF Generator は、チャット対話による即時学習からデータ自動生成・量子化まで、GGUF モデルのオンデバイス作成・再学習・管理を一つの Android アプリで完結します。インタラクティブモードでは会話の中でモデルをリアルタイムに育て、生成した GGUF はそのまま再ロードして続きの学習が可能です。

文書: 操作マニュアル | Retrainable GGUF について | プライバシーポリシー

  • チャット形式でリアルタイムに学習・確認できる インタラクティブモード（新規 GGUF / LoRA）。
  • Brave 検索 / Wikipedia / URL / LLM テーマから Q/A ペアを自動生成し、そのまま学習して GGUF を出力する 自動モード。
  • GGUF を別量子化形式に変換する 量子化変換（F32 / F16 / Q8_0 / Q4_K_M / Q2_K など）。
  • 生成した GGUF は再ロードして追加学習が可能な Retrainable GGUF 形式で出力。

スクリーンショット

主な特徴

  • インタラクティブ学習（新規 GGUF）: NEW LEARN（指示＋応答を新規ペアとして学習）/ RESPONSE LEARN（直前の出力への返答として学習）/ TRY INFERENCE（現在のモデルで推論確認）の 3 操作で、チャット画面上でモデルをリアルタイムに育てます。不正解の場合は自動で再注入学習します。LOAD GGUF でセッションを引き継ぎ、EXPORT GGUF で出力します。
  • インタラクティブ LoRA: 既存 LFM2 GGUF へ LoRA を会話形式でリアルタイム追加学習します。SAVE STATE / RESTORE STATE でセッションを中断・再開でき、EXPORT ADAPTER で llama.cpp 互換アダプタ GGUF を書き出します。
  • 量子化変換: 既存 GGUF を F32 / F16 / Q8_0 / Q4_K_M / Q2_K などの量子化形式に変換します。1-D テンソル（norm ゲイン）は精度保持のため F32 を維持し、行長が非ブロック境界のマトリクスは自動的に F16 にフォールバックします。
  • 自動ペア生成（Auto Pair Gen）: Brave 検索 / Wikipedia / URL 指定 / LLM テーマ指示を入力ソースに RAG 評価付きで Q/A 学習ペアを生成します。フォアグラウンド（FG）・バックグラウンド（BG）実行と停止・再開に対応します。
  • 自動 GGUF 生成（Auto GGUF Gen）: 学習データ（JSONL）と学習方式（GGUF 新規作成・修正 / LFM2 LoRA）を指定してバッチ実行します。F32 / F16 / Q8_0 GGUF を出力します。
  • データ拡張・編集: 生成済みペアを対象に翻訳展開（多言語化）と言い換え増幅でバリエーションを増やせます。ペア編集結果は「最新」として以後の拡張・学習に反映されます。
  • キーワード評価・早期停止: 手動キーワードまたはトークン自動抽出（surprisal 上位）による評価で、合格率が閾値に達したら学習を早期停止します（全学習モード共通）。
  • Ollama 互換サーバ連携: 共通設定の LLM サーバ（既定 http://127.0.0.1:11434）へ接続し、/api/tags でモデル取得、/api/generate で生成、/api/tokenize でトークナイズを利用します。Web AI Chat でブラウザから直接チャットする機能も搭載します。
  • Retrainable GGUF: アプリが出力する GGUF はそのまま再ロードして追加学習が可能です。詳細ページで仕組みと活用方法を解説しています。
  • 端末内完結: 生成物（JSONL / GGUF）は端末の Downloads / Documents / アプリ領域へ保存します。トラッキングや解析情報の収集は行いません。

運用メモ

  • ペア生成・データ拡張は、利用者が設定した LLM サーバ（既定は端末内）や、Brave Search API・Wikipedia・指定 URL への通信を伴います。送信内容・宛先は利用者の入力と操作に依存します。
  • 端末内学習は CPU・メモリを多く使用します。長時間の学習では通知権限・電池最適化除外の許可が推奨されます。
  • 量子化には次元制約があります（Q8_0 は 32 の倍数）。新規作成時のモデル寸法は自動で丸め・縮小されることがあります。
