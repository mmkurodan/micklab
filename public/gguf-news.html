    26.4B MoE (3.4B active) UD-IQ1_S〜UD-Q8_K_XL multimodal Unsloth

    Inkling 2 Mini（Thinking Machines Lab）の GGUF 版を Unsloth が公開

    Thinking Machines Lab が 11月20日に公開した Inkling 2 Mini（Apache-2.0、公式モデルカードでは総 26.4B・アクティブ 3.4B の MoE）を、Unsloth が Dynamic 量子化の GGUF にしました。画像入力に対応し、コンテキストは最大 1M トークン。UD-IQ1_S（約 7.8GB）から UD-Q8_K_XL（約 22.9GB）まであり、UD-Q4_K_M は約 16.6GB です。

    出典: https://huggingface.co/unsloth/Inkling-2-Mini-GGUF

    llama.cpp OpenCL Vulkan

    llama.cpp b12464〜b12555（11/17〜11/19）：OpenCL・Vulkan まわりの改善

    11月19日の b12555 で、OpenCL の分割 flash attention が int8 量子化の KQ 演算に対応しました。11月18日の b12499 では Qualcomm 向け Vulkan の RMS norm が実行時ループ回数で動くよう変更され、11月17日の b12464 では特定構成向けの OpenCL Q8_0 カーネルが追加されています。この期間に新しいモデルアーキテクチャの対応追加は見当たりません。

    出典: https://freedom.tech/project/llama-cpp/

    bartowski が Nex-N2.6（321B）や ZoomGain 4B/9B の GGUF を更新

    bartowski の「Latest from known labs」コレクションで、直近1日以内に Nex-N2.6-GGUF（321.3B、24種の量子化）と ZoomGain-4B / 9B の GGUF が更新されています。ページ上は相対時刻表示のみのため、正確な日付は未確認です。

    出典: https://huggingface.co/collections/bartowski/latest-from-known-labs

    Q4NX AMD NPU Unsloth

    Unsloth Studio v0.1.920-beta：AMD NPU 向け Q4NX 変換に対応

    11月19日のリリースで、Export 画面から Q4NX 形式へ変換し AMD NPU で読み込めるようになりました。LTX-2.5 / MOSS-Image の LoRA 学習や QLoRA の最大 25% 高速化も含まれます。今回のリリース自体に GGUF 関連の変更はありません。

    出典: https://unsloth.ai/docs/new/changelog

    LM Studio llama.cpp bug fix

    LM Studio Bionic 1.2.1：llama.cpp 拡張パック更新と大きなメタデータの GGUF の GPU オフロード修正

    11月16日付の Bionic 1.2.1 で llama.cpp 拡張パック 2.74.0 / 2.76.0 が入り、メタデータヘッダが大きい GGUF で GPU オフロード設定が誤る不具合が直りました。2.76.0 は LM Studio 側のパック番号で、llama.cpp 本体のビルド番号ではありません。

    出典: https://lmstudio.ai/changelog/bionic-v1.2.1

    Ollama llama.cpp b12257 prerelease

    Ollama v0.40.17 はプレリリース継続（rc1）、同梱 llama.cpp を b12257 に更新

    v0.40.17 は rc0（11月10日）・rc1（11月16日）のプレリリース段階で、同梱 llama.cpp の b12257 への更新、MLX の並列生成、Vulkan iGPU での mmap などが含まれます。現時点の安定版は Ripple Preview（65B）を追加した v0.40.16 です。

    出典: https://releasebot.io/updates/ollama
