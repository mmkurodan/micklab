    llama.cpp Inkling 2 speculative decoding

    llama.cpp が Inkling 2 の DSpark 投機的デコードに対応（#32218）

    公式リポジトリに Inkling 2 向け DSpark（ドラフト生成による投機的デコード）対応がマージされた。変換スクリプトと C++ 側の実装が追加され、temperature > 0 時の処理やドラフト状態幅・再シード順の修正、他の DSpark 実装とドラフトトークン数の扱いを揃える変更が含まれる。

    出典: https://github.com/ggml-org/llama.cpp/commit/33aeb17f85869279e3821f746bc645357139bc2c

    llama.cpp ARM Android Q4_0 Q8_0

    llama.cpp：dotprod 非対応の ARMv8.0 向けに Q4_0 / Q8_0 のリパックカーネルを追加（#32142）

    ggml-cpu に、dotprod 命令を持たない 64bit ARMv8.0 CPU 向けの最適化リパックカーネル（Q4_0 / Q8_0）が追加された。Apple 向けアーキテクチャは対象外。古い・廉価な Android 端末での CPU 推論に関係する変更。

    出典: https://github.com/ggml-org/llama.cpp/commit/f20c5907c00c1a7edc32209aa97df992152b10b8

    llama.cpp OpenCL MoE mxfp4

    llama.cpp：OpenCL に MoE 向け coopmat カーネルを追加（#32971）

    OpenCL バックエンドに、cooperative matrix を使う MoE 用カーネルが追加された。対応量子化は q4_0 / q4_1 / q4_k / q5_0 / q5_1 / q5_k / q6_k / mxfp4。同時期に OpenCL の GDN の QK オフセット修正（#32747）も入っている。

    出典: https://github.com/ggml-org/llama.cpp/commit/e6443bd7eb970d940b0669cd9ea0d82d91d620a1

    llama.cpp llama-quantize mixed precision b12669

    llama.cpp b12669：目標サイズに合わせて量子化タイプを自動選択する llama-quantize の新オプション

    llama-quantize に --target-size オプションが追加され、指定したファイルサイズまたは bpw（1重みあたりのビット数）に収まるよう、誤差が最小になる量子化タイプの組み合わせを自動で選べるようになった（PR #15550）。スマホなどメモリ容量が限られた端末向けに、容量ぴったりのGGUFを作りやすくなる。BUILD_SHARED_LIBS=OFF でのリンク不具合の修正も含む。

    出典: https://github.com/ggml-org/llama.cpp/releases/tag/b12669

    llama.cpp Metal BF16 b12668

    llama.cpp b12668：Metal の MUL_MAT / MUL_MAT_ID が BF16・F32 入力に対応

    Apple GPU 向け Metal バックエンドで、行列積（MUL_MAT と MoE 用の MUL_MAT_ID）の入力側（src1）に BF16 と F32 精度を使えるようにする変更（PR #32677）。テンソルAPIが無い環境での BF16 対応や、MoE の精度ポリシー整理も含む。

    出典: https://github.com/ggml-org/llama.cpp/releases/tag/b12668
