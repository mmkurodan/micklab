Android / OCR API / PDF tools

OCR API Server

Formerly: ClarityPDF

OCR API Server turns an Android device into an always-on OCR API that accepts PDFs or images and returns the recognized text as JSON. OCR runs on the device (Tesseract / PaddleOCR / local LLM Vision) and can be used by other apps on the same device or by PCs on the same LAN. On-screen OCR, summaries and AI prompts, plus PDF split / merge / reorder / rasterize / edit tools, remain available in the same app.

Documents: User manual | Privacy policy

  • Tap "Start API" at the top of the home screen and the device becomes an OCR API server (default port 8765).
  • An always-on service: once started, it comes back after the app is closed, the process is killed, or the device reboots.
  • Other apps can start / stop the API with an Intent. Responses include per-line text, confidence and position (blocks / box).

    "page": 1, "text": "…", "confidence": 0.92, "source": "OCR",
    "width": 1080, "height": 2400,
    "blocks": [ { "text": "…", "confidence": 0.95,

  } ],

box is in pixel coordinates of the OCR'd image (width × height; for PDFs, the size after rendering at dpi) with the origin at the top left. Tesseract / PaddleOCR return positions; LLM Vision omits box. See the user manual for details.

Always-on service and external start

  • Always on: Runs as a foreground service and recovers from process kills (automatic restart), swiping the task away, device reboots (restarts on boot), and via a watchdog that checks about every 60 seconds. It stops only when you tap "Stop API", "Exit", "Stop" in the notification, or another app sends a stop request.
  • Kept awake while working: A WakeLock and Wi-Fi lock are held during OCR so processing continues with the screen off. "Exclude from battery optimization" on the home screen makes responses during sleep and automatic recovery more reliable.
  • Start from other apps: Send an explicit Intent (com.micklab.pdf.START_SERVICE / STOP_SERVICE, optional int extra port) with startForegroundService() to start / stop the API without opening the app. A transparent launcher Activity is also provided for devices whose OEM auto-start controls block that.
  • Endpoints at a glance: The home screen lists the endpoint URL for each network interface (tap to copy), and the status / log section shows start, stop, request and error history.

OCR / AI-OCR (on-screen)

  • OCR / text extraction: Extract text from PDFs and images, distinguishing embedded text from OCR, with JSON output. Tesseract (light) supports Japanese (horizontal and vertical), English, Chinese (Simplified/Traditional), Korean, Greek, Russian, Arabic, Hebrew and math; PaddleOCR (high quality) supports Japanese (horizontal and vertical), English, Chinese (Simplified/Traditional), Korean, Arabic and Cyrillic.
  • PDF summary: Summarize the whole file and each page with an LLM, via "OCR→LLM" or "Vision" (page images sent directly to the LLM).
  • AI Prompt: Run any instruction over the whole PDF or page by page. A "Cancel" button stops a running job.
  • LLM integration: Works with Ollama / OpenAI-compatible servers. By default it uses "default Vision" / "default Chat" from the companion app LLM AI Server with llama.cpp, which is started automatically when a job begins if it is not running.

PDF tools

  • PDF editing: Add text, images, shapes and drawings; replace or delete existing text. Bold / italic / underline, rotation, scaling, links (URL), layer reordering and undo. Insert pages (before / after / at the end) or delete pages (the last page cannot be deleted).
  • Multilingual fonts: Noto Sans JP / SC / TC / KR / Arabic / Hebrew / Math and more (all SIL OFL), downloaded on demand when selected. Arabic and Hebrew get automatic right-to-left shaping and bidi reordering.
  • Split, merge, reorder: Extract pages, combine multiple PDFs, reorder by dragging thumbnails.
  • PDF to images / images to PDF: Convert pages to PNG / JPEG (DPI selectable), or combine images into one PDF.

Notes

  • The OCR API has no authentication. Enable it only on trusted local networks and never expose it to external networks.
  • Received files are processed on the device, the result is returned, and the file is discarded afterwards. Nothing is sent to our servers.
  • Network access is limited to the first download of OCR models and fonts, requests to your configured LLM server, and ads. The default LLM endpoint is on-device 127.0.0.1.
  • Recovery may not be possible after a force-stop by an OEM power-saving feature.
