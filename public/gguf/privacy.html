日本語

1. 収集する情報

本アプリ「GGUF Generator」は、解析情報・広告識別子などのトラッキングを一切収集しません。処理は原則として端末内で完結します。以下の情報を端末内に保存します。

  • 設定情報（LLM サーバ URL、生成/埋め込みモデル、生成件数・閾値などの各種パラメータ、学習ハイパーパラメータ、Brave APIキー、既定の保存先）
  • 生成物（Q/A 学習データの .jsonl、学習結果の .gguf、LoRA アダプタ / 統合版 GGUF）。既定では端末の Downloads / Documents またはアプリ保存領域に保存されます。
  • 処理ログ（アプリ内の処理状況・エラー情報）

利用者が入力したテキスト（キーワード、テーマ、URL、資料本文、学習ペア、プロンプト等）は、生成・学習処理のために利用されます。

2. 通信

本アプリは、利用者が設定・操作した場合にのみ、次の宛先へ通信します。送信内容・宛先は利用者の入力と選択に依存します。

  • LLM AI サーバ（既定 http://127.0.0.1:11434 = 端末内）: プロンプトや資料テキストを送信して応答を取得します（/api/generate、/api/tags、/api/tokenize など）。既定は端末内のため、インターネットを経由しません。
  • Brave Search API: 入力キーワードを検索クエリとして送信します（API キー利用時）。
  • Wikipedia: 入力キーワードで記事を取得します。
  • 利用者が指定した URL: 本文取得のためアクセスします。
  • ローカルのファイル取り込み（.jsonl / .gguf の選択）は端末内で完結し、外部サーバー通信は行いません。

本アプリの開発者が、利用者のデータを収集・保管・第三者提供することはありません。

3. 権限

  • インターネット / ネットワーク状態: 上記の外部通信のため。
  • ストレージ: 生成物の保存・読み込みのため。
  • 通知 / フォアグラウンドサービス / WakeLock / 電池最適化除外: バックグラウンドでのペア生成・学習を継続するため。

4. 利用目的

上記データは、アプリの動作、学習データ生成、端末内学習、GGUF 出力、表示のためにのみ使用します。外部送信・第三者提供・利用者を追跡する目的での保存は行いません。

5. 保存期間

設定・生成物・ログは、利用者が削除するかアプリのデータを消去するまで端末内に保持されます。ログはアプリ内の「クリア」で削除できます。

English

1. Information Collected

This application ("GGUF Generator") does not collect any tracking data such as analytics or advertising identifiers. Processing is, in principle, completed on the device. The following data is stored locally on the device:

  • Configuration data (LLM server URL, generation/embedding models, parameters such as sample count and thresholds, training hyperparameters, Brave API key, default save location)
  • Outputs (Q/A training data .jsonl, trained .gguf, LoRA adapter / merged GGUF). By default these are saved to the device's Downloads / Documents or the app storage area.
  • Processing logs (in-app operational status and error information)

Text entered by the user (keywords, themes, URLs, source text, training pairs, prompts, etc.) is used for generation and training processing.

2. Communication

The app communicates with the following destinations only when configured and operated by the user. The content sent and the destinations depend on your input and choices.

  • LLM AI server (default http://127.0.0.1:11434, i.e. on-device): sends prompts and source text to obtain responses (/api/generate, /api/tags, /api/tokenize, etc.). Because the default is on-device, it does not go over the internet.
  • Brave Search API: sends the input keyword as a search query (when an API key is used).
  • Wikipedia: fetches articles by the input keyword.
  • A URL specified by the user: accessed to retrieve its text.
  • Local file import (selecting .jsonl / .gguf) is completed on the device and involves no external server communication.

The developer of this app does not collect, store, or provide user data to third parties.

3. Permissions

  • Internet / network state: for the external communication above.
  • Storage: for saving and reading outputs.
  • Notifications / foreground service / WakeLock / battery-optimization exemption: to keep pair generation and training running in the background.

4. Purpose of Use

The data above is used solely for application functionality, training-data generation, on-device training, GGUF export, and display. It is not transmitted externally, shared with third parties, or stored for the purpose of tracking users.

5. Retention Period

Settings, outputs, and logs are retained on the device until the user deletes them or clears the application data. Logs can be deleted using the "Clear" option in the app.
