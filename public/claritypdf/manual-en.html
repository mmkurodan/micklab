User Manual

This page is a guide to OCR API Server (formerly ClarityPDF), based on the current Android implementation. It is adapted from the in-app documentation for the public site.

Related: Privacy policy

1. General

  • From top to bottom the home screen shows: ① OCR API Server (status, start/stop, port, endpoints), ② OCR / AI-OCR, ③ Convert & compose PDF, ④ Create & edit PDF, ⑤ Settings, ⑥ Status / log. Sections ②–⑥ open and close when you tap their heading.
  • Input files are read-only; the original is never modified. Results are always saved as new files.
  • Choose the output location with "Output" on each screen. If none is set, files go to "Download/PDFToolkit" on the device.

2. OCR API Server

Tap "Start API" at the top of the home screen and the device becomes an OCR API server. Send a PDF or image and it returns the recognized text as JSON. Other apps on the device and PCs or devices on the same LAN can use it.

⚠️ There is no authentication. Use it only on trusted local networks and never expose it to external networks.

Always on

  • Once started, it keeps running as a background service with a notification even after the app is closed, and restarts automatically after the process ends or the device reboots. It stops only when you tap "Stop API", "Exit" or "Stop" in the notification, or when another app sends a stop request.
  • Allowing "Exclude from battery optimization" on the home screen makes responses during sleep and automatic recovery more reliable (on Android 12+ it is required for watchdog recovery).
  • A WakeLock and Wi-Fi lock are held during OCR so processing continues with the screen off.
  • The port can be changed while stopped. Tap an endpoint URL to copy it.
  • Recovery may not be possible after a force-stop by an OEM power-saving feature.

Endpoints

PurposeURL
OCR requestPOST http://<device-ip>:<port>/ocr
From the same devicePOST http://127.0.0.1:<port>/ocr
Health checkGET http://<device-ip>:<port>/health → {"status":"ok"}

The default port is 8765.

Request (multipart/form-data)

FieldRequiredDescription
fileYesImage (PNG/JPEG/WebP/BMP) or PDF
enginetesseract (default) | paddleocr | llm
langComma-separated language codes (default: eng), e.g. jpn / jpn,eng / jpn_vert (vertical) / chi_sim / kor
dpiPDF rendering resolution 36–600 (default 150); echoed in the response

Response (HTTP 200)

{
  "pages": [ {
    "page": 1, "text": "Recognized text", "confidence": 0.92, "source": "OCR",
    "width": 1080, "height": 2400,
    "blocks": [ { "text": "…", "confidence": 0.95,
                  "box": { "left": 40, "top": 120, "right": 620, "bottom": 168 } } ]
  } ],
  "engine": "Tesseract", "languages": ["jpn", "eng"], "dpi": 150, "pageCount": 1
}

blocks holds the text and position of each recognized line. box is in pixel coordinates of the OCR'd image (width × height; for PDFs, the size after rendering at dpi) with the origin at the top left. Tesseract and PaddleOCR return box; LLM Vision has no positions and omits it.

Errors

HTTPMeaning
400{"error":"Missing 'file' field"} — no file field
400{"error":"Could not decode image"} — image decode failed
400{"error":"Unknown engine: xxx"} — invalid engine name
500{"error":"..."} — OCR processing error

curl examples

# OCR a JPEG with English Tesseract
curl -X POST http://192.168.1.10:8765/ocr \
     -F "file=@document.jpg" -F "engine=tesseract" -F "lang=eng"

# OCR a PDF in Japanese + English (multi-page, 300 dpi)
curl -X POST http://192.168.1.10:8765/ocr \
     -F "file=@scan.pdf;type=application/pdf" -F "lang=jpn,eng" -F "dpi=300"

# Vertical Japanese with PaddleOCR
curl -X POST http://192.168.1.10:8765/ocr \
     -F "file=@tategaki.png" -F "engine=paddleocr" -F "lang=jpn_vert"

# Health check
curl http://192.168.1.10:8765/health

Python example

import requests

with open("document.pdf", "rb") as f:
    resp = requests.post(
        "http://192.168.1.10:8765/ocr",
        files={"file": ("document.pdf", f, "application/pdf")},
        data={"engine": "tesseract", "lang": "jpn,eng"},
    )
result = resp.json()
for page in result["pages"]:
    print(f"Page {page['page']}: {page['text'][:80]}...")
    for b in page.get("blocks", []):
        print("  ", b["text"], b.get("box"))

Starting from other apps (Intent)

The service is exported. Send an explicit Intent with startForegroundService() to start or stop the API without opening this app. The calling app must be in the foreground.

ItemValue
componentcom.micklab.pdf / com.micklab.pdf.api.OcrApiService
Start actioncom.micklab.pdf.START_SERVICE (optional int extra port, 1024–65535; defaults to the saved port)
Stop actioncom.micklab.pdf.STOP_SERVICE
// Caller's AndroidManifest.xml (Android 11+):
// <queries><package android:name="com.micklab.pdf" /></queries>
val intent = Intent()
    .setClassName("com.micklab.pdf", "com.micklab.pdf.api.OcrApiService")
    .setAction("com.micklab.pdf.START_SERVICE")
    .putExtra("port", 8765)
ContextCompat.startForegroundService(context, intent)
// Verify: GET http://127.0.0.1:8765/health
adb shell am start-foreground-service -n com.micklab.pdf/.api.OcrApiService \
  -a com.micklab.pdf.START_SERVICE --ei port 8765
  • For devices whose OEM auto-start controls (such as ZTE/Nubia AutoLaunch) reject startForegroundService from other apps, a transparent launcher Activity is also provided (same action com.micklab.pdf.START_SERVICE, optional int extra port). This app comes to the front and starts the service itself.
  • On Android 13+ the service works without notification permission, but no notification is shown (open the app once and tap "Start API" to be asked for the permission).
  • Large PDFs take time (several to tens of seconds per page). engine=tesseract with lang=jpn needs the Tesseract Japanese model; PaddleOCR / LLM likewise need their models and settings.

3. OCR / AI-OCR (on-screen)

  • OCR / text extraction: Extract text from PDFs and images, distinguishing embedded text (already in the file) from OCR (image recognition), with JSON output. Choose Tesseract (light) or PaddleOCR (high quality). Tesseract supports Japanese (horizontal and vertical), English, Chinese (Simplified/Traditional), Korean, Greek, Russian (Cyrillic), Arabic, Hebrew and math (equ); PaddleOCR supports Japanese (horizontal and vertical), English, Chinese (Simplified/Traditional), Korean, Arabic and Cyrillic (each language model is downloaded once). Large documents can run in the background.
  • PDF summary: Summarize the whole file and each page with an LLM, via "OCR→LLM" or "Vision" (page images sent directly to the LLM).
  • AI Prompt: Run any instruction over the whole PDF or page by page, via "OCR→LLM" or "Vision". While running, the button becomes "Cancel".
  • The first time a model is used, a confirmation explains that loading may take a while. A warning appears if the Vision model is still the placeholder.

4. Convert & compose PDF

  • Split (extract pages): Open a PDF, select pages, then output them as one PDF or one file per page.
  • Merge: Select several PDFs, set the order, and combine them into one.
  • Reorder: Drag thumbnails to change the page order and save as a new PDF.
  • PDF to images: Convert each page to PNG / JPEG at a chosen DPI.
  • Images to PDF: Select several images, set the order, and combine them into one PDF.

5. Create & edit PDF

  1. Open a PDF with "Select PDF", or use "Create blank" to make empty pages with a chosen paper size and background color. A notice explains that adding, changing or moving text may alter fonts or formatting.
  2. Move between pages with "◀ Prev / Next ▶". Use the page-actions menu to insert a blank page (before / after the current page or at the end) and the delete button to remove the current page (disabled when there is only one page).
  3. Add text: Type text (line breaks allowed), choose size, color, style and font, then "Add". Drag it into place on the preview.
  4. Add image: Pick an image with "Image"; drag to move, scale and rotate.
  5. Add shape: Choose rectangle / ellipse, stroke color, fill and stroke width, then drag on the canvas.
  6. Draw: Choose brush color and width and draw freehand (undo supported).
  7. Background: Choose a color under "Background" and "Apply" to fill the whole page.
  8. Edit existing text: Tap text on the preview to select it, then enter replacement text or choose "Delete original". The original font, size, color and style are kept unless you change them.
  9. Layers: Added and edited items appear under "Layers". Tap to select, ▲▼ to reorder, × to delete.
  10. "Apply" bakes the current edits into a temporary PDF and refreshes the preview. Shapes and drawings stay as layers after Apply.
  11. "Apply and save" writes the final PDF. Leaving without saving asks for confirmation.

Adding or editing text needs an embedded font. Choose from Noto Sans JP / Noto Serif JP / M PLUS Rounded 1c / Zen Kaku Gothic New / Klee One / Noto Sans / Noto Sans SC / TC / KR / Noto Sans Arabic / Hebrew / Noto Sans Math / Symbols 2 (all SIL OFL); each is downloaded on demand when first selected. Noto families are labeled by the script they cover (e.g. Chinese (Simplified)). Arabic and Hebrew (right-to-left) are shaped and bidi-reordered automatically.

6. Settings

  • OCR settings & model management: Download Tesseract / PaddleOCR language models; set the LLM (Ollama / OpenAI-compatible) URL, model and connection check. Order: Tesseract → PaddleOCR → LLM.
  • LLM defaults and auto-start: The Vision (OCR) model defaults to "default Vision" and the text model to "default Chat" (bundled configs of the companion app LLM AI Server with llama.cpp). If the LLM server is not running, the app tries to start it when a summary or OCR job begins.
  • Language: 日本語 / English / Français / Deutsch / Español / Italiano / Português / 中文（简体）/ 한국어.
  • User manual / Privacy policy / Licenses: These documents (the text can be copied on each screen).

7. Status / log and offline use

  • "Status / log" on the home screen shows the history of API start, stop, requests and errors.
  • PDF and image processing completes on the device. Network access is limited to the first download of OCR models and fonts, requests to your configured LLM server, and ads (the default LLM endpoint is on-device 127.0.0.1).
  • If you specify an external LLM server, page images and extracted text are sent there. The destination depends on your settings.
