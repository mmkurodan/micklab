生成ロジックはすべて公開されています。以下の手順を別の環境で実装すれば、同じ入力から同じコードが得られることを確認できます。

1. 入力値の正規化

  • 識別子: 前後の空白を除去し、小文字化
  • 回次: 0 以上の整数（先頭の 0 は除去。01 → 1）
  • Word1〜3: それぞれ前後の空白を除去し、小文字化

2. Word のソート

正規化後の 3 単語を辞書順（UTF-16 コード単位の昇順 = JavaScript の Array.prototype.sort() 既定順）に並べ替えます。入力順は結果に影響しません。

並べ替え後、次の形式で 1 つの文字列に連結します。

識別子|回次|Word1|Word2|Word3

例: example|1|apple|coffee|river

3. Argon2id によるハッシュ化

連結した文字列（UTF-8）を Argon2id（version 1.3）でハッシュ化します。

password    : 連結文字列 (UTF-8)
salt        : "code-generator-v1" (UTF-8 / 固定値)
memory      : 65536 KiB (64 MiB)
iterations  : 3
parallelism : 1
hashLength  : 32 bytes

Argon2 は仕様上 salt が必須のため、公開の固定値を使用しています。

4. Base64URL 変換

32 バイトのハッシュを Base64URL（+→-、/→_、末尾の = なし）に変換し、43 文字のシード文字列を得ます。

5. 文字種へのマッピング

選択された文字種を「英小文字 → 英大文字 → 数字 → 記号」の順に連結したものを文字セット（n 文字）とします。

英小文字: abcdefghijklmnopqrstuvwxyz
英大文字: ABCDEFGHIJKLMNOPQRSTUVWXYZ
数字    : 0123456789
記号    : !@#$%^&*()-_=+[]{};:,.<>?

シードから次のようにバイト列を生成します（i = 0, 1, 2, … と必要なだけ続ける）。

block(i) = SHA-256( シード文字列 + "|" + i )
バイト列 = block(0) || block(1) || block(2) || …

各バイト b を先頭から順に文字へ変換します。偏りを防ぐため、範囲外のバイトは読み飛ばします。

limit = 256 - (256 mod n)
b < limit  → 文字セット[b mod n] を出力
b ≥ limit → 読み飛ばす

6. 最終生成（切り出しと文字種の保証）

  • 出力された文字列の先頭から、指定されたコード長ぶんを候補として切り出します。
  • 候補が、選択されたすべての文字種を最低 1 文字ずつ含んでいれば、それが生成コードです。
  • 含んでいない場合はその候補を破棄し、続きの文字列から次のコード長ぶんを候補として同じ判定を繰り返します。

検証用の例

識別子: example / 回次: 1
Word : Coffee, River, apple
コード長: 20 / 文字種: すべて ON

連結文字列: example|1|apple|coffee|river
シード    : 0tHI3SFmdBrEDTnuzmBkAPse7tzkFdSLKZcme9rTweo
生成コード: 77?c.hOO)EMV=kjSLea?

Argon2id の実装には hash-wasm 4.12.0（MIT License, © Dani Biró）をこのファイル内に埋め込んで使用しています。SHA-256 はブラウザ標準の Web Crypto API を使用しています。

本ツールは公開ロジックに基づきコードを生成します。

安全性はWord1〜Word3の秘密性に依存します。

入力値はブラウザ内のみで処理され、保存・送信されません。

同じ入力値からは常に同じコードが生成されます。
