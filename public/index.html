GGUF モデル最新情報

5 件

更新日: 2026-11-22（日本時間）· 12B 以下の GGUF モデルと llama.cpp の更新

9B Q4_K_M / Q5_K_M / Q8_0 vision SenseNova

SenseNova が公式に SenseNova-Loop-9B の GGUF を公開

SenseTime 系の SenseNova による画像+テキスト入力の 9B モデル（2026-11-17 公開）の公式 GGUF。一部の層を2回実行するループ型デコーダで、最大 512K コンテキスト、Apache 2.0。モデルカードでは OpenSenseNova の llama.cpp フォーク利用が案内されており、本家での対応は明記されていない。

出典: https://huggingface.co/sensenova/SenseNova-Loop-9B-GGUF

4B Q4_K_M〜IQ2_M bartowski

bartowski が Spark-X2.6-4B の GGUF を公開

XHToken の 4B モデルの GGUF。BF16 から IQ2_M まで 22 種類の量子化があり、Q4_K_M は約 2.6GB。思考量を low/high で切り替える設定を持ち、英語・中国語対応、Apache-2.0。1.7B 版の GGUF も同時に公開されている。

出典: https://huggingface.co/bartowski/Spark-X2.6-4B-GGUF

llama.cpp 新アーキテクチャ 8B (A1B)

llama.cpp が Zyphra の Zaya1 8B アーキテクチャに対応

PR #32071 が 2026-11-18 にマージ。CCA 層・通常のアテンション層・top-1 ルーティングの MoE FFN を組み合わせたハイブリッド構成（総 8B / アクティブ 1B）を llama.cpp で実行できるようになった。

出典: https://github.com/ggml-org/llama.cpp/pull/32071

llama.cpp Vulkan b12612

llama.cpp b12612：Vulkan の MMVQ を AMD RDNA4 向けに高速化

Q3_K・Q5_K・IQ4_XS の量子化行列ベクトル積について RDNA4 GPU での性能を改善（AMD 純正ドライバでは従来設定を維持）。シェーダ読み込み処理の整理も含む（PR #31804）。

出典: https://github.com/ggml-org/llama.cpp/releases/tag/b12612

llama.cpp 不具合修正 NVFP4

llama.cpp b12611：NVFP4 MoE のスケール欠落を修正

モデル読み込み時、一部の層の NVFP4 MoE エキスパートが専用スケールの付与前に複製され、スケールなしで動いていた不具合を修正（PR #32704）。

出典: https://github.com/ggml-org/llama.cpp/releases/tag/b12611
